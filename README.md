# tasbih-uz

Onlayn tasbeh — [tasbih.uz](https://tasbih.uz)

Plain HTML/CSS/JS, no build step. Hosted on Netlify.

- Tap anywhere or press Space to count
- 6 dhikrs, targets 33 / 99 / 100 / ∞
- Results saved in the browser (localStorage)

See [GUIDE.md](GUIDE.md) for deploy, domain, Google Analytics and Search Console setup.
